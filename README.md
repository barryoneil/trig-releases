# Trig releases

Installers for Trig, a desktop website scanner. Download the latest version from [Releases](https://github.com/barryoneil/trig-releases/releases/latest).

- **Windows:** `Trig-Setup-<version>.exe`
- **Linux:** `Trig-<version>.AppImage`

Installed copies update themselves from this page. This repository only holds release files; the source is private.
